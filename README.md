# simple-chat

> A TUI-based chat client for local networks, featuring encryption and ssh-like host configuration.

## What it is

simple-chat lets you chat with others on the same network (which can be a LAN, a tailscale tailnet or similar) via a
simple terminal UI. It requires no internet connection, no accounts, no third-party servers, no nothing.
You control everything, and you're the only one who sees the message unencrypted.
